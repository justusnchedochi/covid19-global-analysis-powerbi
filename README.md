# COVID-19 GLOBAL DATA ANALYSIS USING POWER BI

## Project Overview

This project presents a global analysis of COVID-19 data using **Microsoft Power BI**. The aim of the project was to examine major COVID-19 trends across countries and continents and present the findings through data cleaning, data modelling, calculations, and visual analysis.

The dataset used for this project was downloaded on **2 March 2026**. The analysis focuses on COVID-19 cases, deaths, infection rates, stringency measures, case fatality rates, population differences, and country-level disease burden.

## Research Questions

The project was designed to answer important questions about the global spread and impact of COVID-19, including:

* How did daily COVID-19 cases change over time?
* How did the global stringency index change during the pandemic?
* What relationship exists between total cases per million and total deaths per million?
* Which countries had the highest cumulative number of cases?
* How did infection rates differ across countries with different population sizes?
* What was the relationship between GDP per capita and case fatality rate across continents?
* How did the ranking of the five most infected countries change over different quarters?
* What was the average global case fatality rate?
* Which five countries recorded the highest total COVID-19 cases?
* Which continent recorded the highest peak in smoothed new cases?

## Data Preparation

The data was first loaded into **Power Query**, where it was reviewed and prepared for analysis. Data cleaning was carried out to improve the quality and structure of the dataset.

The data was then organised into separate tables to support effective analysis. These included a **Location Table**, **Calendar Table** and **Facts Table**.

## Data Modelling

A relational data model was created in Power BI. The tables were connected using appropriate relationships, including a **one-to-many relationship** between the Facts and Location tables.

The final model provided a structured foundation for analysis and allowed information from the different tables to work together correctly.

## DAX Calculations

Several DAX measures were created to support the analysis. These included:

* **Total Cases**
* **Total Deaths**
* **Infection Rate**
* **Average Stringency Index**
* **Case Fatality Rate (CFR%)**

These measures were used to calculate and compare important COVID-19 indicators across countries, continents and time periods.
